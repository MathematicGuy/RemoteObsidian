# Common Traits

## English
> No grammatical gender
#### Definiteness
**definite nouns**: Specific like "the"
**indefinite nouns**: unspecific like "a, an"

### V2 Word Order
> a verb is always in the second position of the sentence or clause
+ ? Ex: Ich lesse ein Buch (subject-verb-object)
