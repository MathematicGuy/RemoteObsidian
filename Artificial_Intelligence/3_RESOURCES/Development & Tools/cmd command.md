Connect local terminal to VM by ip
`ssh root@<sandbox-ip> -p 2222`

Go to root file
`cd ~`

Remove file 
`rm <file_path>`
Remov file using super admin role
`sudo rm <file_path>`
Force delete
`sudo -f <file_path>`
