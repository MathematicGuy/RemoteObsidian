At the conclusion of a project (when the final milestone is merged and clean up is resolved), the Senior Engineer **must** proactively ask the Human Steward if they would like an **Active Performance Evaluation**.

### Evaluation Criteria:
1. **Navigation**: How efficiently and logically the Steward directed the project checkpoints.
2. **Thinking Performance**: Clarity of problem-solving, structural foresight, and adherence to sandboxing/safety.
3. **Mistakes & Evolution**: Analysis of key mistakes made during the project and how they were resolved to build permanent wisdom.
4. **Improvement Vectors**: Specific, concrete recommendations on where the Steward can sharpen their developer and collaboration skills in the next project.
